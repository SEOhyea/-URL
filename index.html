1. 서비스와 개인정보 처리 목적

가족갤러리는 초대코드로 가입한 가족이 로그인하여 사진·영상·음악·스토리를 함께 보관하고 열람하는 서비스입니다. 개인정보는 가입과 로그인, 가족 접근 권한 관리, 파일 업로드·공유·다운로드, 앨범 및 스토리 작성·재생, 화면 설정, 보안 및 문의 처리에 사용합니다. 광고를 표시하거나 광고 타기팅에 개인정보를 사용하지 않습니다.

2. 접근·수집·이용하는 정보

가입·인증 정보
사용자가 입력한 아이디, 가족에게 보일 이름, 비밀번호, 초대코드를 처리합니다. 비밀번호는 확인을 위해 전송되며 서버에는 복원이 어려운 해시 형태로 저장합니다. 내부 사용자·기기 식별값, 역할, 연결 상태, 초대코드의 해시·유효기간·사용 여부와 로그인 세션 정보도 처리합니다. 가입 항목으로 이메일이나 전화번호를 요구하지 않습니다.
사용자가 선택하거나 작성한 콘텐츠
업로드한 사진·영상·MP3 음악·배경사진, 파일명·형식·크기·날짜·등록 시각·무결성 확인값, 미리보기 이미지, 앨범 이름 및 구성, 스토리 제목·본문·날짜·콘텐츠 구성, 스토리용 별도 사본과 생성한 MP4 영상을 저장합니다. 사진·영상 원본에 촬영 장소 등의 메타데이터가 들어 있으면 원본과 함께 보관·공유될 수 있습니다.
연결·설정·보안 정보
서버 주소, 로그인 유지 쿠키, 화면 테마와 음악 설정 등을 기기 또는 서버에 저장합니다. 접속 IP 주소 및 브라우저·앱 요청 정보는 통신과 인증에 사용되며, IP 주소와 로그인 시도 정보는 반복 로그인 실패 제한에도 사용됩니다. 서버 운영 중 오류·실행 로그가 생성될 수 있습니다.
문의 정보
이메일로 문의하거나 삭제를 요청하면 발신 이메일 주소, 문의 내용 및 사용자가 제공한 계정 식별 정보를 처리합니다. 문의에 비밀번호나 초대코드를 포함하지 마세요.

3. 저장 위치와 공유 대상

계정과 업로드 콘텐츠는 가족갤러리 서버로 사용하는 PC의 저장소에 보관합니다. 가족갤러리는 로그인한 가족 간 공유를 목적으로 하므로, 같은 서버에 접근 권한을 받은 가족은 공유 갤러리·앨범·스토리·음악과 관련 표시 정보를 열람하거나 내려받을 수 있습니다. 서버 관리자는 계정과 콘텐츠를 관리할 수 있습니다. 개별 앨범이 가족 구성원마다 자동으로 분리되는 비공개 공간은 아닙니다.

사용자가 다른 가족의 기기에 내려받게 하거나 앱 밖으로 전달한 파일은 별도 사본이 됩니다. 서버에서 원본을 삭제해도 다른 가족의 기기나 별도 보관 장소에 있는 사본까지 자동 삭제되지는 않습니다.

운영자는 개인정보를 판매하거나 광고업체에 제공하지 않습니다. 외부 서비스의 사용 범위는 다음과 같습니다.

  • Cloudflare: 서비스 도메인의 DNS 운영에 사용합니다. 현재 안내된 운영 구성은 DNS 전용이며, 사진·영상 원본의 클라우드 저장 서비스로 사용하지 않습니다. DNS 질의와 관련된 정보 처리는 Cloudflare 개인정보처리방침을 참고하세요.
  • GitHub: 이 개인정보처리방침과 삭제 요청 안내 웹페이지의 공개 게시에 사용합니다. 해당 페이지 접속 시 IP 주소 등 접속 정보가 GitHub에 의해 처리될 수 있습니다. 가족갤러리의 계정 DB나 가족 사진을 이 저장소에 게시하지 않습니다. GitHub 개인정보처리방침
  • Google Gmail: 사용자가 문의 이메일로 보낸 이메일과 첨부파일은 운영자의 Gmail 계정에서 수신·처리합니다. Google 개인정보처리방침

외부 서비스 이용 과정에서는 각 제공자의 정책에 따라 해외 인프라에서 관련 정보가 처리될 수 있습니다. 법령에 따른 적법한 요청이 있는 경우에는 필요한 범위에서 정보를 제공할 수 있습니다.

4. 개인정보의 보안 처리

  • 앱과 공개 서버 사이의 통신에 HTTPS를 사용하며 Android 앱은 평문 HTTP 연결과 유효하지 않은 인증서를 허용하지 않습니다.
  • 비밀번호는 개별 솔트를 적용한 scrypt 해시로 저장하고, 초대코드와 인증 토큰도 서버에서 해시로 관리합니다.
  • 자료 조회에는 인증을 요구하며 작성자·관리자 권한에 따라 수정·삭제를 제한합니다. 로그인 시도 제한과 요청 위조 방지 검사를 적용합니다.
  • 공개 HTTPS 연결의 로그인 쿠키에는 HttpOnly, Secure, SameSite 속성을 적용합니다. Android 앱의 운영체제 자동 백업은 비활성화되어 있습니다.

사진·영상 등 PC에 보관된 파일 자체를 앱이 별도로 암호화하여 저장하는 구조는 아닙니다. 서버 PC와 백업에 접근할 수 있는 관리자는 파일을 열람할 수 있습니다. 서버 운영 환경의 접근 통제와 저장 장치 보호가 함께 필요합니다.

5. 보관 기간과 삭제 방식

공유 콘텐츠와 계정 정보는 가족 보관함 서비스를 제공하기 위해 보관하며, 아래 삭제 조치 또는 운영자의 삭제 처리 전까지 유지됩니다. 현재 콘텐츠와 계정에 일괄 적용되는 자동 만료 기간은 없습니다.

사진·영상과 휴지통
일반 삭제는 휴지통 이동입니다. 휴지통에서 영구 삭제를 선택하면 서버 갤러리 원본·미리보기와 관련 갤러리 기록을 삭제합니다. 휴지통에는 자동 비우기 기한이 없습니다. 스토리 제작 과정에서 만들어진 별도 사본이나 MP4, 백업, 다른 기기의 다운로드 사본은 별도로 처리해야 합니다.
앨범·스토리·음악
앨범 삭제는 앨범 구성을 삭제하며 사진·영상 원본은 남깁니다. 스토리 삭제는 목록에서 숨기는 방식으로 스토리 기록·사본·렌더링 파일이 서버에 남을 수 있습니다. 음악 목록에서 제외하는 기능 역시 음악 원본의 영구 삭제가 아닙니다. 이러한 자료의 완전 삭제는 운영자에게 요청할 수 있습니다.
계정·기기 연결
로그아웃, 앱 제거, 기기 연결 해제 또는 관리자의 이용 차단만으로 계정 정보와 업로드 자료가 모두 삭제되지는 않습니다. 현재 앱에는 계정과 관련 데이터를 한 번에 영구 삭제하는 기능이 없습니다. 계정 및 관련 데이터 삭제는 아래 문의 창구로 요청하세요.
세션·초대·임시 전송 정보
로그인 세션은 발급 후 최대 30일간 유효하며 로그아웃하면 해당 세션을 삭제합니다. 만료 세션은 새 세션 발급 시 정리합니다. 초대코드는 발급 후 24시간 동안 한 번만 사용할 수 있으며, 만료가 기록의 즉시 삭제를 뜻하지는 않습니다. 24시간 넘게 갱신되지 않은 미완료 업로드는 서버 시작 또는 업로드 정리 절차가 실행될 때 제거합니다.
운영 로그·백업·문의
운영 로그는 용량에 따라 순환 보관하며 고정된 일수에 따른 삭제가 아닙니다. 별도로 만든 백업은 운영자가 정리하기 전까지 남으며, 운영 저장소의 삭제가 기존 백업에 자동 반영되지는 않습니다. 이메일 문의 기록은 문의 처리와 후속 대응에 필요한 동안 보관하며 삭제를 요청할 수 있습니다.

계정 또는 자료의 완전 삭제를 요청하면 운영자가 요청자와 삭제 범위를 확인하여 처리합니다. 스토리 사본·생성 영상·운영자가 보유한 백업도 삭제 검토 대상에 포함합니다. 현재 자동 처리 기한은 없으며, 실제 처리 일정·완료 여부와 즉시 삭제할 수 없는 자료 및 사유는 문의 답변으로 안내합니다.
